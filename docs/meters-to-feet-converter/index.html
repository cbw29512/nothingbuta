How to convert meters to feet

One meter equals approximately 3.28084 feet. To convert meters to feet, multiply the meter value by 3.28084. The calculator above uses that conversion and displays the result to three decimal places.

For example, 1 meter is about 3.281 feet, 5 meters is about 16.404 feet, and 10 meters is about 32.808 feet. This conversion is useful for room dimensions, construction measurements, sports distances, travel, height, and other metric-to-imperial comparisons.

If you need the opposite conversion, use the Feet to Meters converter from the All Tools page.
